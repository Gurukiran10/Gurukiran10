### 🧭 How I build

1. **Verify, don't trust.** "Done" is a claim; a separate verifier checks the real system state.
2. **The LLM writes, code decides.** Counting, limits and rules belong in tested code.
3. **Write the evals first.** Held-out tasks are frozen before the first run.
4. **Humans own the decisions.** Money, people and anything irreversible get a checkpoint.
